# Scroll-Driven Hero Section Animation

An interactive hero section featuring smooth car movement, animated typography, and impact statistics revealed through scrolling.

## Tech Stack
- React.js + Vite
- Tailwind CSS
- JavaScript, HTML, CSS
- GSAP + ScrollTrigger

## Features
- Smooth headline entrance animation
- Scroll-controlled car movement
- Staggered statistics animations
- Responsive layout

## Getting Started

```bash
git clone https://github.com/YOUR_USERNAME/scroll-animation-project.git
cd scroll-animation-project
npm install
npm run dev
```
